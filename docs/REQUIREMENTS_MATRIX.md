# Матрица соответствия ТЗ

Статус отражает состояние версии 2.2.0 на 28.09.2026.

| Требование | Статус | Реализация / доказательство |
|---|---|---|
| Android 8.0+ | Выполнено | `minSdk = 26` |
| Портрет от 360 dp | Выполнено в эмуляторе | portrait в Manifest, адаптивный Compose |
| Локальный профиль без контактов | Выполнено | Room; вводится только игровое имя питомца |
| Офлайн-цикл | Выполнено | отсутствует INTERNET permission и сетевые SDK |
| Только игровая валюта | Выполнено | локальные монеты; billing отсутствует |
| 9+ вариантов питомца | Выполнено | 12 комбинаций в `pet_variants.json` |
| 3+ стадии роста | Выполнено | малыш, подросший, взрослый |
| 5 периодов | Выполнено | дни 1–5, сохранение и воспроизводимый прогресс |
| 6+ заданий, 3 темы | Выполнено | 12 игр, три образовательные темы |
| 8+ покупок двух типов | Выполнено | 8 базовых товаров, обязательные и желания |
| 3+ цели | Выполнено | игрушка, домик, игровой комплекс; также недельная цель |
| Распределение бюджета | Выполнено | доходы, обязательные, желания, накопления |
| Нехватка средств | Выполнено | покупка отклоняется с суммой дефицита и советом |
| Награды и объяснение | Выполнено | монеты только за первое прохождение, итоговый экран |
| Повтор без повторной награды | Выполнено | `AwardGameResult` |
| Сохранение после перезапуска | Выполнено | Room/SQLite |
| Взрослый раздел и сброс | Выполнено | проверка 6+3, диалог подтверждения, полный сброс |
| Отключение анимации и звука | Выполнено | локально сохраняемые переключатели |
| Нет рекламы, платежей, соцсети | Выполнено | отсутствуют разрешения и SDK |
| Учебный контент отделён от UI | Выполнено частично | основные справочники в assets; уровни интерактивных игр пока также описаны в Kotlin |
| Автотесты формул | Выполнено | 7 unit-тестов экономики |
| APK для демонстрации | Выполнено | `FinnyPet.apk`, release-вариант подписан debug-ключом |
| Production-подпись RuStore | Требует владельца | нужен закрытый ключ владельца приложения |
| Физическое устройство 3 ГБ+ | Требует проверки | эмулятор проверен; физическое устройство не заявляется как проверенное |
| Иконка RuStore 512×512 | Требует финального ассета | launcher есть, отдельный подтверждённый PNG для магазина не подготовлен |
| 3 скриншота | Выполнено для прототипа | QA-скриншоты находятся в корне проекта |
| PPTX/PDF и видео до 3 минут | Требует подготовки | не входят в текущую сборку приложения |
| Права на все изображения/звуки | Требует подтверждения владельца | перечень библиотек есть; происхождение пользовательских ассетов нужно подтвердить |
| Git-репозиторий | Требует упаковки | исходники готовы, но каталог пока не инициализирован как Git |

Незакрытые пункты не маскируются: они требуют ключа публикации, физического устройства, подтверждения прав или отдельного демонстрационного материала.
