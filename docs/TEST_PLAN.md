# Тест-план и отчёт

## Автоматические проверки

Файл `EconomyTest.kt` проверяет:

1. точную шкалу наград;
2. экономику пяти дней;
3. баланс уровней «Весов»;
4. запрет отрицательного баланса;
5. задачи на сдачу;
6. обязательные бюджеты;
7. границы оценки «Копилки».

## Ручной smoke-набор

| Сценарий | Ожидаемый результат |
|---|---|
| Первый запуск | Онбординг → выбор питомца → три финансовых принципа → дом |
| Перезапуск | Открывается сохранённый профиль |
| Сброс | Есть подтверждение; после сброса открывается выбор питомца |
| Покупка при нехватке | Баланс не меняется, показана цена, остаток и недостающая сумма |
| Обязательная/необязательная покупка | Тип подписан словами, изменение баланса сохранено |
| Повтор уровня | Лучший результат сохраняется, монеты повторно не выдаются |
| Новый день | Показано объявление и информация о новых уровнях |
| Отключение анимации | Питомец перестаёт «дышать»/плавать; настройка сохраняется |
| Карта | Нажатие открытого здания запускает переход; закрытое показывает условие |
| Весы | Карточка переносится на чашу, балка и чаши реагируют |
| Копилка | Копилка двигается, монеты и желания падают и сталкиваются |
| Гонка расходов | Товары движутся по дорожкам, корзина меняет полосу, лимит соблюдается |

## Фактический статус

- Kotlin-компиляция: пройдена.
- Release APK и release lint: пройдены.
- 7 unit-тестов присутствуют и компилируются; в текущей Windows-среде запуск Gradle Test Executor блокируется системной ошибкой загрузки `GradleWorkerMain`, поэтому успешный прогон в этом отчёте не заявляется.
- Установка и запуск debug APK на эмуляторе Android 8.0: пройдены.
- Экран 360 dp: главный экран, карта, список заданий и «Весы» проверены визуально.
- Широкий экран эмулятора (1600×2560, 240 dpi): рабочая область остаётся по центру и не растягивается на всю ширину.
- «Весы»: перенос карточки жестом на чашу меняет сумму и вызывает наклон балки; проверено на эмуляторе.
- Остальные аркады после переработки компилируются, но полный ручной проход каждой пока не подтверждён.
- Физическое устройство с RAM 3 ГБ+: ещё не проверено; это нельзя отмечать выполненным без реального устройства.

Перед публичной сдачей выполнить полный проход пяти дней на чистом профиле и повторить smoke-набор на физическом Android 8+.
