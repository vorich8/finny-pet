# Происхождение ассетов и ограничения использования

В `app/src/main/res/drawable-nodpi/` добавлены пять изображений предметов, переданных заказчиком 28.09.2026: `good_candy.jpg`, `good_medicine.jpg`, `good_icecream.jpg`, `good_salad.jpg`, `good_pizza.jpg`. Они используются только как внутриигровые иллюстрации.

Восемь файлов `app/src/main/res/raw/sfx_*.wav` синтезированы собственным скриптом `tools/generate_sfx.py` из математических волн. Сторонние записи, музыкальные библиотеки, сэмпл-паки и звуковые заглушки не используются. Это оригинальные материалы проекта без обязательств перед сторонними правообладателями аудио.

Перед публичной публикацией в RuStore владелец проекта должен подтвердить права на распространение переданных изображений и остальных графических ресурсов приложения. Наличие файлов в демонстрационном репозитории само по себе не устанавливает лицензию для третьих лиц.

Зависимости Kotlin, AndroidX, Compose, Room и Hilt перечислены в Gradle-файлах проекта. Их лицензии и версии следует зафиксировать в финальном релизном пакете.
