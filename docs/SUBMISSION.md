## Ограничения проверки

- Текущий исходный код — 2.3.1; существующий APK в GitHub Release — 2.3.0. Не выдавать старый APK за сборку 2.3.1.
- APK 2.3.0 подписан debug-ключом; для RuStore требуется production-ключ владельца.
- Проверка на физическом устройстве пропущена по запросу; проверялся эмулятор.
- Часть процедурных уровней игр пока остаётся в Kotlin.
- Резервного демонстрационного видео в проекте не найдено.
- Права на предоставленную пользователем иконку следует подтвердить перед публикацией в магазине.
